# FlowState Automations — Website & Landing Page

Official landing page and design assets for FlowState Automations.

## Structure
- `index.html` — Main landing page markup with semantic sections, responsive layouts, and accessible navigation.
- `styles.css` — Modern design system tokens, typography (Syne & Outfit), custom color palette, and micro-interactions.
- `img/` — Brand assets, including SVG vector logos and PNG graphics.
- `DESIGN.md` — Design system specifications, color codes, typography hierarchy, and UI guidelines.
- `PRODUCT.md` — Core value proposition, target audiences, and messaging voice.

## Previewing
Open `index.html` directly in any web browser or serve it locally using a live server (e.g. `npx serve .` or VS Code Live Server extension).
